# 7_submission_checklist

## Naming and packaging rules
- [ ] Use Group ID prefix `7_` in all filenames.
- [ ] ZIP file name format: `7_partA_<short_project_title>.zip`
- [ ] ZIP extension only (`.zip`), no `.rar`.
- [ ] No binaries in submission archive.
- [ ] GitHub repository should contain normal folder/files (not zip inside repo).

## Team submission rule
- [ ] Exactly one group member submits on LMS/portal.
- [ ] Other members do not submit (not even blank submission).

## Code and plot rules
- [ ] All scripts/manifests/csv/report files follow `7_` prefix.
- [ ] Plot scripts must be `.py` only (no `.ipynb`).
- [ ] Plot scripts must hardcode values.
- [ ] CSV files should be submitted separately; do not read CSV as plot input if disallowed by rubric.

## Report structure (Part A)
- [ ] (1) Project Title
- [ ] (2) Team Members
- [ ] (3) Problem
- [ ] (4) Motivation
- [ ] (5) Objectives
- [ ] (5) Background
- [ ] (6) Methodology/Design
- [ ] (7) (Initial) Implementation
- [ ] (8) Evaluation & observations
- [ ] (9) Outcomes & Conclusion
- [ ] (10) References

## Final validation
- [ ] All commands rerun on fresh cluster and produce expected artifacts.
- [ ] Report text polished manually.
- [ ] All figures visible in report PDF.
- [ ] ZIP opens correctly and contains expected structure.
